## 第一步：注册 Supabase 账号（2分钟）

1. 打开浏览器，访问 **[supabase.com](https://supabase.com)**
2. 点击右上角绿色的 **"Start your project"** 按钮
3. 选择 **GitHub 登录**（推荐）或者用邮箱注册
4. 登录成功后，你会看到 Supabase 的控制面板

---

## 第二步：创建数据库项目（2分钟）

1. 在控制面板中，点击橘黄色的 **"New project"** 按钮

2. 填写项目信息：

   | 字段 | 填写内容 |
   |------|----------|
   | **Name** | `gaoyijiuban`（随便填就行） |
   | **Database Password** | 设置一个密码，比如 `Gjyb2026!`（**记下来！后面可能用到**） |
   | **Region** | 选 **Northeast Asia (Seoul)** 或者 **Southeast Asia (Singapore)**，离中国近 |

3. **Pricing Plan** 选 **Free**（免费的就够用）

4. 点击绿色的 **"Create project"**

5. 等待 1-2 分钟，页面会显示 "Project is ready"，然后自动跳转到项目面板

---

## 第三步：创建数据库表（3分钟）

1. 在左侧菜单栏，点击 **"SQL Editor"**（图标是 `</>`）

2. 点击左上角绿色的 **"New query"** 按钮

3. 现在打开你的电脑文件夹 `C:\Users\Administrator\Desktop\banjiwanghan\supabase\`

4. 用记事本打开 **`schema.sql`**，全选（Ctrl+A）→ 复制（Ctrl+C）

5. 回到 Supabase 网页，粘贴到 SQL Editor 的空白区域

6. 点击右下角绿色的 **"Run"** 按钮

7. 看到 "Success. No rows returned" 就表示成功了 ✅

8. 再次点击 **"New query"**，这次用记事本打开 **`seed.sql`**，同样复制粘贴 → 点击 **Run**

9. 验证一下：左侧菜单点击 **"Table Editor"**，你应该能看到 6 张表：

   ```
   ✅ class_info
   ✅ events
   ✅ gallery_photos
   ✅ literature_figures
   ✅ members
   ✅ messages
   ```

## 第四步：创建照片存储（1分钟）

1. 左侧菜单点击 **"Storage"**（文件夹图标）

2. 点击 **"New bucket"** 按钮

3. 填写：
   - Name: `class-photos`
   - ✅ 勾选 **"Public bucket"**
   - File size limit: `10 MB`

4. 点击绿色的 **"Create bucket"**

---

## 第五步：获取连接信息（1分钟）

1. 左侧菜单点击 **"Project Settings"**（齿轮图标 ⚙️）→ **"API"**

2. 你会看到两个重要信息：
   - **Project URL**：类似 `https://abcdefghijklm.supabase.co`
   - **anon public key**：一串很长的字母（以 `eyJ` 开头）

3. **把这两个都复制下来，暂时粘贴到记事本里备用**

---

## 第六步：配置网站连接（1分钟）

1. 用记事本打开 `C:\Users\Administrator\Desktop\banjiwanghan\index.html`

2. 按 `Ctrl+G`，输入 `334`，跳转到第 334 行，你会看到：

   ```javascript
   const SUPABASE_URL = 'https://YOUR-PROJECT.supabase.co';
   const SUPABASE_ANON_KEY = 'YOUR-ANON-KEY';
   ```

3. 把刚才复制的 **Project URL** 替换第一行的 `https://YOUR-PROJECT.supabase.co`

4. 把刚才复制的 **anon public key** 替换第二行的 `YOUR-ANON-KEY`

   > ⚠️ 注意保留两边的单引号 `' '`

   改完之后应该像这样：
   ```javascript
   const SUPABASE_URL = 'https://abcdefghijklm.supabase.co';
   const SUPABASE_ANON_KEY = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.xxxxxx很长的字符串xxxxx';
   ```

5. 保存文件（Ctrl+S）
